Start with this criterion: Given WMS pick confirmation data is available and processed as described, when the report is generated by 6am for each picker, per shift, per day, with short picks counted as confirmed quantity less than task quantity, cancelled lines excluded, and wrong-location scans included, then the shift leads can use the report to target retraining.
3. Write tests from ACCEPTANCE.md, including the error cases, before the code they cover.
4. Stop and ask before touching anything in Out of scope, or anything that depends on the 3 open questions in SPEC.md.
5. Check GUARDRAILS.md before anything that touches data handling or a review point.
